# 2. Helm: Chuẩn hóa và Quản lý ứng dụng Cloud-Native
## 1. Helm là gì?
Nếu Kubernetes là hệ điều hành của cụm máy chủ, thì Helm đóng vai trò là trình quản lý gói (tương tự như apt trên Ubuntu hoặc pip trên Python).

Helm giúp bạn quản lý các ứng dụng Kubernetes thông qua các Charts, giúp việc cài đặt, cập nhật và chia sẻ các cấu hình YAML phức tạp trở nên đơn giản và có thể lặp lại.

## 2. Tại sao cần Helm cho các dự án AI?
Các ứng dụng AI (như hệ thống Inference hay Training) thường đi kèm với rất nhiều thành phần:
* Nhiều Deployments (Frontend, Backend, Model Server).
* Các cấu hình GPU Operator.
* Cấu hình mạng (Services, Ingress).
* Lưu trữ (Persistent Volumes).
Thay vì phải chạy hàng chục lệnh kubectl apply -f, bạn chỉ cần một lệnh helm install duy nhất để triển khai toàn bộ hệ thống.

## 3. Ba khái niệm cốt lõi của Helm
### 3.1. Chart
Một gói chứa tất cả các tài nguyên cần thiết để chạy một ứng dụng trên Kubernetes. Nó bao gồm các file template YAML và các file cấu hình.

### 3.2. Repository (Kho lưu trữ)
Nơi các Chart được chia sẻ và lưu trữ. Bạn có thể thêm các repo phổ biến như:
* Bitnami: Chứa các ứng dụng chuẩn (Database, Web servers).
* NVIDIA: Chứa các công cụ hỗ trợ GPU.

### 3.3. Release (Bản thực thi)
Khi bạn cài đặt một Chart vào Cluster, một Release sẽ được tạo ra. Bạn có thể chạy nhiều Release của cùng một Chart (ví dụ: model-v1 và model-v2) trong cùng một Cluster.

### 4. Cấu trúc thư mục của một Helm Chart
Một Chart cơ bản (ví dụ: my-ai-app) sẽ có cấu trúc như sau:

```text
my-ai-app/
├── Chart.yaml          # Thông tin về tên, phiên bản của Chart
├── values.yaml         # Các tham số cấu hình (CPU, RAM, Image tag,...)
├── charts/             # Các Chart phụ thuộc (nếu có)
└── templates/          # Các file YAML mẫu (Deployment, Service,...)
    ├── deployment.yaml
    ├── service.yaml
    └── _helpers.tpl    # Các hàm hỗ trợ định dạng
```
### 5. Sức mạnh của values.yaml (Tham số hóa)
Thay vì sửa trực tiếp vào file YAML gốc, bạn chỉ cần thay đổi thông số trong values.yaml.
Ví dụ: Để thay đổi số lượng bản sao hoặc mức ngưỡng HPA:

```YAML
# values.yaml
replicaCount: 3
image:
  repository: my-model-server
  tag: "v1.0"
resources:
  limits:
    nvidia.com/gpu: 1
```

> Một số lệnh thường dùng [cheat sheet](https://helm.sh/docs/intro/cheatsheet/)
