# 3. Hướng dẫn cài đặt Kubernetes Cluster và Helm
Tài liệu này hướng dẫn chi tiết cách thiết lập một cụm Kubernetes (Single Node) phiên bản v1.31 trên hệ điều hành Ubuntu, bao gồm cả việc cài đặt công cụ quản lý Helm.

> [File script](../bash/install.sh)

## 1. Chuẩn bị hệ thống (Prerequisites)
Trước khi cài đặt, hệ thống cần được cấu hình để đáp ứng các yêu cầu khắt khe của Kubernetes về mạng và tài nguyên.

### 1.1. Tắt Swap
Kubernetes yêu cầu tắt Swap để đảm bảo hiệu suất và tính ổn định của bộ nhớ.

```bash
sudo swapoff -a
sudo sed -i '/swap/d' /etc/fstab
```

### 1.2. Cấu hình Kernel Modules
K8s cần các module overlay và br_netfilter để quản lý lưu lượng mạng giữa các container:

```bash
cat <<EOF | sudo tee /etc/modules-load.d/k8s.conf
overlay
br_netfilter
EOF

sudo modprobe overlay
sudo modprobe br_netfilter
```

### 1.3. Cấu hình Sysctl cho Bridging
Thiết lập cho phép Iptables kiểm tra lưu lượng cầu nối (bridge):

```bash
cat <<EOF | sudo tee /etc/sysctl.d/k8s.conf
net.bridge.bridge-nf-call-iptables  = 1
net.bridge.bridge-nf-call-ip6tables = 1
net.ipv4.ip_forward                 = 1
EOF

sudo sysctl --system
```
## 2. Cài đặt Container Runtime (containerd)
Chúng ta sử dụng containerd làm runtime chính thức.


1. **Cài đặt các gói phụ trợ:** Lưu ý tên gói chính xác là apt-transport-https (tránh thiếu dấu gạch ngang).

```bash
sudo apt update
sudo apt install -y apt-transport-https ca-certificates curl gpg conntrack
```
2. **Cài đặt containerd.io:** Sử dụng repository chính thức của Docker.
```bash
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg \
  | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \
  https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" \
  | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt update
sudo apt install -y containerd.io
```

3. **Cấu hình SystemdCgroup:** Đây là bước quan trọng để Kubelet quản lý tài nguyên chính xác. Cần tạo file config mặc định và sửa giá trị SystemdCgroup thành true.
```bash
sudo mkdir -p /etc/containerd
sudo containerd config default | sudo tee /etc/containerd/config.toml > /dev/null
sudo sed -i 's/SystemdCgroup = false/SystemdCgroup = true/g' /etc/containerd/config.toml
sudo systemctl restart containerd
```
## 3. Cài đặt các công cụ Kubernetes (v1.31)
### 3.1. Thêm Repository

Lưu ý: Lệnh thêm repo phải nằm trên một dòng duy nhất để tránh lỗi Malformed entry khi apt update.

```bash
curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.31/deb/Release.key | sudo gpg --dearmor -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg

echo 'deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.31/deb/ /' | sudo tee /etc/apt/sources.list.d/kubernetes.list
```
### 3.2. Cài đặt Kubeadm, Kubelet và Kubectl
```bash
sudo apt update
sudo apt install -y kubelet kubeadm kubectl
sudo apt-mark hold kubelet kubeadm kubectl
```
## 4. Khởi tạo Cluster
### 4.1. Chạy Kubeadm Init
Sử dụng dải mạng Pod 10.244.0.0/16 cho Flannel.

```bash
sudo kubeadm init --pod-network-cidr=10.244.0.0/16
```
<!-- Nếu gặp lỗi thiếu conntrack, hãy đảm bảo đã cài đặt gói này trước khi chạy init. -->

### 4.2. Cấu hình quyền truy cập cho User
```bash
mkdir -p $HOME/.kube
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
sudo chown $(id -u):$(id -g) $HOME/.kube/config
```
### 4.3. Cài đặt Flannel Network
Cần tạo thư mục /run/flannel trước khi triển khai để tránh lỗi khởi động.

```bash
sudo mkdir -p /run/flannel
kubectl apply -f https://github.com/flannel-io/flannel/releases/latest/download/kube-flannel.yml
```
### 4.4. Cho phép chạy Pod trên Control Plane (Single Node)
Mặc định K8s không cho phép chạy ứng dụng trên node điều khiển. Gỡ bỏ Taint để sử dụng cluster một node.

```bash
kubectl taint nodes --all node-role.kubernetes.io/control-plane-
```
## 5. Cài đặt các thành phần bổ trợ (Add-ons)
### 5.1. Metrics Server
Dùng để thu thập dữ liệu hiệu năng (CPU/RAM). Cần cấu hình --kubelet-insecure-tls để hoạt động trong môi trường lab.

```bash
kubectl apply -f https://github.com/kubernetes-sigs/metrics-server/releases/latest/download/components.yaml
kubectl patch deployment metrics-server -n kube-system --type='json' -p='[{"op":"add","path":"/spec/template/spec/containers/0/args/-","value":"--kubelet-insecure-tls"}]'
``` 
### 5.2. Local Path Provisioner
Cung cấp khả năng lưu trữ dữ liệu bền vững (Persistence Storage) bằng ổ đĩa cục bộ.

```bash
kubectl apply -f https://raw.githubusercontent.com/rancher/local-path-provisioner/v0.0.26/deploy/local-path-storage.yaml
kubectl patch storageclass local-path -p '{"metadata":{"annotations":{"storageclass.kubernetes.io/is-default-class":"true"}}}'
```
## 6. Cài đặt Helm
Sử dụng script cài đặt tự động cho phiên bản mới nhất.

```bash
curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-4 | bash
```
## 7. Kiểm tra trạng thái cuối cùng
```bash
kubectl get nodes   # Kiểm tra trạng thái Ready 
kubectl get pods -A # Đảm bảo các pod hệ thống đều Running 
helm version        # Kiểm tra phiên bản Helm 
```
Lưu ý: Nếu cụm Flannel bị kẹt ở trạng thái "Terminating", có thể cần can thiệp vào finalize của namespace để xóa sạch.
